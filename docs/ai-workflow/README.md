# AI 개발 워크플로 — 포인터

멀티 에이전트 설계 워크플로(Claude = Chief Architect·최종 결정권 / GPT = 독립 검증자 /
Codex = 저장소 근거 검증·구현 / Git·GitHub = 기준점)의 **정본은 전용 저장소에 있다**:

> **정본**: `brovior/ai-dev-workflow`
> (역할·결정권, 7단계 워크플로, GPT 호출 채널 A/B, 보안 모델, 채택 스캐폴더)

이 저장소(`ontology-core`)는 **소비자가 import만 하는 안정 라이브러리**로 수정이 오너 승인
예외에 한정되므로, 어댑터(브릿지·Action)를 설치하지 않고 이 포인터만 둔다.

## 이 저장소에 적용되는 요약

| 항목 | 내용 |
|---|---|
| core 변경 절차 | 워크플로에서 설계·검증을 마친 뒤 **오너 승인 하에만** 반영 (기존 §2-2 예외 절차 — v0.3.0/v0.4.0 선례) |
| core 설계 결정 기록 | core에 닿는 결정도 ADR은 **소비자 저장소**(`ontology-extractor/docs/ai-workflow/adr/`)에 남긴다 — 그릇 확장 요구는 소비자 쪽에서 발생하기 때문(결정 이력 단일화) |
| core 코드 원문 검증 | 필요 시 PC에서 Codex CLI(read-only 샌드박스)로 이 저장소를 직접 탐색 — 정본 README §3 옵션 |
| 보안 | GPT/Codex는 외부(OpenAI) 서비스 — 커밋된 파일 외에는 어떤 채널로도 반출하지 않는다 |
